# AI Air Canvas 🎨🤖

A real-time virtual drawing tool built with Python and Computer Vision. Point your index finger at the camera to draw, and open your palm to instantly wipe the canvas.

## Tech Stack
* **Python:** Core application logic.
* **Google MediaPipe (Tasks API):** 3D hand tracking and gesture recognition.
* **OpenCV:** Live video capture, masking, and rendering.
* **NumPy:** Manages the virtual canvas as a mathematical matrix.

## How to Run
1. Clone the repository.
2. Install the requirements: `pip install -r requirements.txt`
3. Run the script: `python air_canvas.py`
